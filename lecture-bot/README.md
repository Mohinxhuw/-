# بوت تلخيص المحاضرات (تيليجرام)

يرسل الطالب تسجيل المحاضرة (صوت أو فيديو أو رسالة صوتية) أو رابط يوتيوب أو Google Drive، فيرجع له البوت:

- ملخصاً بالعناوين والنقاط يصله جزءاً جزءاً أثناء الكتابة، وبجانب كل نقطة وقتها في التسجيل
- المصطلحات الإنجليزية كما هي مع معناها بالعربي
- أسئلة اختيار من متعدد، وأسئلة صح أو خطأ (ترسل أيضاً كاختبار تفاعلي داخل تيليجرام)
- بطاقات مراجعة (الجواب مخفي حتى يضغط عليه الطالب)
- النص الكامل للمحاضرة
- ملف PDF يجمع كل ما سبق

ويمكن للطالب:
- إرسال المحاضرة على عدة أجزاء أو رسائل صوتية متتالية، أو محاضرتين من المادة نفسها، فتُجمع في ملخص واحد
  (ينتظر البوت 40 ثانية بعد آخر ملف، أو يضغط الطالب «ابدأ الآن»)
- إرسال شرائح المحاضرة (PDF أو PowerPoint) وصور السبورة، فيقرأها Claude، وتُعطى مصطلحاتها لمحرّك
  تحويل الكلام إلى نص ليكتبها صحيحة
- اختيار لهجة المحاضر بالأمر /dialect (خليجية، مصرية، شامية، عراقية، مغاربية، سودانية، يمنية)

## ما تحتاجه

| الشيء | من أين | التكلفة |
|---|---|---|
| رمز البوت `TELEGRAM_BOT_TOKEN` | @BotFather في تيليجرام | مجاني |
| مفتاح Claude `ANTHROPIC_API_KEY` | console.anthropic.com | حسب الاستخدام |
| خادم يعمل 24 ساعة (VPS) | Hetzner أو Contabo أو غيرها | شهري |
| مفتاح Groq `GROQ_API_KEY` (موصى به) | console.groq.com/keys | مجاني ضمن حد يومي، ثم قرابة 0.11 دولار لساعة الصوت |

**عن السرعة:** مع مفتاح Groq يُحوَّل الكلام إلى نص بنموذج whisper-large-v3 الكامل (أدق من النموذج
المحلي)، ومحاضرة الساعة تأخذ دقيقة تقريباً، ثم دقيقتين إلى خمس لكتابة الملخص. يُقسَّم الصوت إلى
مقاطع 10 دقائق عند لحظات الصمت وتُرسل معاً. إن تعطل Groq يكمل البوت بالنموذج المحلي تلقائياً.

بدون مفتاح Groq يتم التحويل على الخادم نفسه: على معالج 4 أنوية تأخذ محاضرة الساعة قرابة 25 إلى 30
دقيقة. خادم بكرت شاشة NVIDIA أسرع بكثير: ضع `WHISPER_DEVICE=cuda` و`WHISPER_COMPUTE_TYPE=float16`.

## التشغيل على الخادم (Docker)

```bash
git clone <رابط المستودع>
cd lecture-bot
cp .env.example .env
nano .env            # ضع TELEGRAM_BOT_TOKEN و ANTHROPIC_API_KEY
docker compose up -d --build
docker compose logs -f bot   # لمتابعة عمل البوت
```

## ملفات أكبر من 20 ميغابايت

خوادم تيليجرام لا تسمح للبوتات بتنزيل ملفات أكبر من 20 ميغابايت، ومحاضرة ساعة غالباً أكبر من ذلك.
الحل: تشغيل خادم Bot API خاص (مضمّن في `docker-compose.yml`) يرفع الحد إلى 2 غيغابايت:

1. ادخل https://my.telegram.org ← API development tools، وأنشئ تطبيقاً، وخذ `api_id` و`api_hash`.
2. شغّل سكربت التثبيت (`install.sh`) وأدخلهما عندما يسألك. أو أضف إلى `.env` يدوياً:
   ```
   TELEGRAM_API_ID=...
   TELEGRAM_API_HASH=...
   TELEGRAM_LOCAL_API_URL=http://telegram-bot-api:8081
   COMPOSE_PROFILES=bigfiles
   ```
   ثم `docker compose up -d --build`. البوت ينفّذ `logOut` من خوادم تيليجرام تلقائياً أول مرة.

بدون هذه الخطوة يعمل البوت، ويطلب من الطالب إرسال ملف أصغر أو رابط يوتيوب.

## التجربة بدون تيليجرام

```bash
pip install -r requirements.txt
python cli.py محاضرة.m4a --major medicine --out ./out
python cli.py جزء1.m4a جزء2.m4a --docs شرائح.pptx --dialect gulf
python cli.py محاضرة.m4a --mock   # بدون Claude، لتجربة التفريغ والـ PDF فقط
```

## أوامر البوت

| الأمر | الوظيفة |
|---|---|
| /start | الترحيب وطريقة الاستخدام |
| /major | اختيار التخصص (يحسّن دقة المصطلحات) |
| /dialect | لهجة المحاضر (تحسّن فهم الكلام، والملخص يبقى بالفصحى) |
| /privacy | سياسة الخصوصية |
| /delete | حذف كل البيانات المحفوظة للطالب |

## الخصوصية

- التسجيل والملفات والصور تُحذف من الخادم فور انتهاء المعالجة.
- مع مفتاح Groq يُرسل صوت المحاضرة إلى Groq لتحويله إلى نص، ونص المحاضرة والشرائح إلى Claude.
- يُحفظ فقط نص آخر 5 محاضرات للطالب وأسئلتها (لتعمل أزرار الاختبار والبطاقات)، ويستطيع حذفها بـ /delete.

| `lecturebot/render.py` | إنشاء ملف PDF بالعربية |
| `lecturebot/pipeline.py` | ربط الخطوات كلها |
