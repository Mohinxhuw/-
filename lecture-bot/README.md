# بوت تلخيص المحاضرات (تيليجرام)

يرسل الطالب تسجيل المحاضرة (صوت أو فيديو أو رسالة صوتية) أو رابط يوتيوب أو Google Drive، فيرجع له البوت:

- ملخصاً بالعناوين والنقاط يصله جزءاً جزءاً أثناء الكتابة، وبجانب كل نقطة وقتها في التسجيل
- المصطلحات الإنجليزية كما هي مع معناها بالعربي
- زر «اختبرني» بأنواع الأسئلة: اختيار من متعدد وصح أو خطأ (اختبار تفاعلي داخل تيليجرام)، وأسئلة مقالية
  يكتب الطالب إجابتها فيصححها Claude ويعطيه درجة من 10 وما نقص إجابته
- بطاقات مراجعة (الجواب مخفي حتى يضغط عليه الطالب)
- «التقسيمات»: رسم لكل تقسيم صرّح به المحاضر (أقسام كذا، أنواعه، مراحله) فقط، وجداول مقارنة لكل مقارنة في الشرح
- النص الكامل للمحاضرة
- ملف PDF يجمع كل ما سبق

وبعد كل محاضرة يستطيع الطالب أن يطلب **شرحاً أبسط** لأي جزء منها مع مثال. وتُضاف بطاقاتها إلى **مراجعة يومية متباعدة**
(/review، بتذكير يومي في الوقت الذي يختاره بـ /reminder)، ويستطيع أن يجمع عدة محاضرات في
**ملخص ليلة الاختبار** (/exam).

**التنظيم:** كل محاضرة تُحفظ في **مكتبة** الطالب (/library) تحت مادتها (يعرفها البوت من موضوع المحاضرة،
ويستطيع الطالب تغييرها)، مع **بحث** في كل المحاضرات بالكلمة والدقيقة (/search)، و**موعد اختبار** لكل مادة
يتبعه **عدّاد أيام** و**خطة مذاكرة** توزّع المحاضرات على الأيام الباقية، وتصل مهمة كل يوم في التذكير اليومي.

**المشاركة:** نسخة إنجليزية بملف PDF، وتصدير Word
وMarkdown لـ Notion، ورابط مشاركة يضع المحاضرة في مكتبة الزميل، و**مجموعات دراسة** (/groups) يصل فيها ما
يرسله أحد الأعضاء للجميع.

**النمو:** إحصاءات الطالب (/stats) ومنها نسبة إجاباته الصحيحة والمحاضرات التي تحتاج مراجعة، ورابط دعوة
(/invite): كل صديقين = 60 نجمة في المحفظة. و**نسخة المعلم** (/teacher): ورقة اختبار ونموذج إجابة وملف Word، ورابط اختبار
يحلّه الطلاب في تيليجرام وتصل نتائجهم بـ /results.

ويمكن للطالب:
- إرسال المحاضرة على عدة أجزاء أو رسائل صوتية متتالية، أو محاضرتين من المادة نفسها، فتُجمع في ملخص واحد
  (ينتظر البوت 40 ثانية بعد آخر ملف، أو يضغط الطالب «ابدأ الآن»)
- إرسال شرائح المحاضرة (PDF أو PowerPoint) وصور السبورة، فيقرأها Claude، وتُعطى مصطلحاتها لمحرّك
  تحويل الكلام إلى نص ليكتبها صحيحة

## المحاضرات بالإنجليزية

تحت التسجيل زر «🌐 لغة المحاضرة». باختيار English يُحوَّل الكلام إلى نص بالإنجليزية، ويُكتب الملخص بالعربية
مع بقاء كل مصطلح بالإنجليزية بجانب معناه، وتبقى الأسئلة والإجابات النموذجية بالإنجليزية كما في الاختبار،
والشرح بالعربية. يحفظ البوت اختيار الطالب لمحاضراته التالية. وزر «📖 المصطلحات» تحت الملف يعرض مصطلحات
المحاضرة، و«📖 مصطلحات المادة» في صفحة المادة يجمع قاموس المادة كلها.

## محاكاة الاختبار والدليل

- **⏱ محاكاة الاختبار** (من صفحة المادة في /library): عشرون سؤالاً من كل محاضرات المادة، واحد بعد الآخر
  بوقت محدد (دقيقة للاختيار من متعدد، ونصف دقيقة لصح أو خطأ). في النهاية الدرجة ونسبة الجاهزية والمحاضرات
  التي تحتاج مراجعة، وتظهر آخر نسبة جاهزية في صفحة المادة.
- **📍 الدليل:** تحت كل سؤال زر يعرض كلام المحاضر الذي بُنيت عليه الإجابة، ووقته في التسجيل، وسياقه من النص.

## التوفير والمشاركة

- **لا تُعالَج المحاضرة مرتين:** يعرف البوت التسجيل المكرر (نفس ملف تيليجرام أو نفس رابط يوتيوب/Drive) قبل
  تنزيله، فيرسل الملخص المحفوظ فوراً بلا تكلفة. النتائج في `data/cache`.
- **ملخص بلا تسجيل:** شرائح المحاضرة أو صور صفحات الكتاب وحدها تكفي (زر «📄 لخّص الملفات وحدها»).
- **المشاركة التلقائية في المجموعة:** كل عضو يربط المجموعة بإحدى مواده (يسأله البوت مرة واحدة)، فتصل محاضرات
  تلك المادة للأعضاء تلقائياً وتُحفظ في المادة المرتبطة عند كل واحد منهم.
- **اختبار شامل للمادة:** من صفحة المادة في /library، عشرون سؤالاً من كل محاضراتها، وتتكرر أكثر أسئلة المحاضرات
  التي أخطأ فيها الطالب.

## المحفظة والأسعار (نجوم تيليجرام)

يشحن الطالب محفظته مرة واحدة بنجوم تيليجرام (/wallet)، ويُخصم منها مع كل استخدام بلا نافذة دفع كل مرة.
الدفع **متوقف** حتى يرسل المالك `/billing on` (أو `BILLING_ENABLED=true`)، وكل شيء مجاني قبل ذلك.

| الاستخدام | السعر |
|---|---|
| محاضرة جديدة | ⭐ 1.5 للدقيقة (الساعة الأولى لكل طالب جديد مجاناً) |
| محاضرة من زميل أو مجموعة، أو تسجيل سبق تلخيصه | ⭐ 5 (أول 3 مجاناً)، ويعود ⭐ 1 لصاحبها |
| ملخص من الشرائح أو الكتاب وحدها | ⭐ 60 |
| اشرح لي أبسط (لكل جزء) | ⭐ 10 |
| تصحيح سؤال مقالي | أول اثنين لكل محاضرة مجاناً، ثم ⭐ 5 |
| النسخة الإنجليزية | ⭐ 30 (إعادة إرسالها مجانية) |
| ملخص ليلة الاختبار | ⭐ 50 |
| المكتبة والاختبارات والبطاقات والمراجعة والخطة | مجاناً دائماً |

الباقات: 100، و250 (+25 هدية)، و500 (+75)، و1000 (+200). لا يُخصم شيء إن فشلت المعالجة. وإن لم يكفِ
الرصيد تُحفظ المحاضرة المرسلة، ويظهر بعد الشحن زر «▶️ أكمل»؛ ومحاضرات الزملاء تصل مقفلة بزر «🔓 افتحها».
الأسعار في أول `bot_wallet.py`. ويجيب البوت على /paysupport (تيليجرام يطلبه)، فيصل طلب الطالب للمالك.

## أدوات المالك

يطبع `install.sh` في آخره رمز المالك. أرسل للبوت `/owner الرمز` مرة واحدة، فتصير مالكه، ثم:
- `/compare`: أرسل بعده محاضرة، فيحوّلها البوت إلى نص مرة واحدة ويكتب ملخصها وأسئلتها مرتين: بـ Opus وحده، وبالنموذج المختلط،
  ويرسل الملفين مع تكلفة كل واحد وتقدير تكلفة ساعة المحاضرة، لتختار النموذج.
- `/billing on` أو `/billing off`: تشغيل الدفع أو إيقافه.
- `/refund رقم_الطالب`: استرداد آخر شحنة لطالب (تعود النجوم إليه من تيليجرام).

## الدقة

يكتب Claude الملاحظات والأسئلة في طلبين متوازيين بمستوى تفكير عالٍ (`CLAUDE_EFFORT=high`)، بتعليمات
صريحة: لا معلومة لم يقلها المحاضر، ولا تخمين في المقاطع غير الواضحة، ولا اختصار يغيّر المعنى. وكل سؤال
يرفق اقتباساً من نص المحاضرة يدعم إجابته؛ يتحقق البوت أن الاقتباس موجود فعلاً في النص، ويحذف السؤال
إن لم يكن.

**النموذج المختلط** (الافتراضي): Opus يكتب الملاحظات، وSonnet يكتب الأسئلة، ثم يراجع Opus كل سؤال
على نص المحاضرة ويحذف كل سؤال خاطئ أو مبهم أو له أكثر من إجابة صحيحة. ولكتابة الأسئلة بـ Opus أيضاً: اجعل
`QUESTIONS_MODEL` مثل `CLAUDE_MODEL`.

## ما تحتاجه

| الشيء | من أين | التكلفة |
|---|---|---|
| رمز البوت `TELEGRAM_BOT_TOKEN` | @BotFather في تيليجرام | مجاني |
| مفتاح Claude `ANTHROPIC_API_KEY` | console.anthropic.com | حسب الاستخدام |
| خادم يعمل 24 ساعة (VPS) | Hetzner أو Contabo أو غيرها | شهري |
| مفتاح Groq `GROQ_API_KEY` (موصى به) | console.groq.com/keys | مجاني ضمن حد يومي، ثم قرابة 0.11 دولار لساعة الصوت |

**عن السرعة:** مع مفتاح Groq يُحوَّل الكلام إلى نص بنموذج whisper-large-v3 الكامل (أدق من النموذج
المحلي)، ومحاضرة الساعة تأخذ دقيقة تقريباً، ثم دقيقتين إلى خمس لكتابة الملخص. يُقسَّم الصوت إلى
مقاطع 10 دقائق عند لحظات الصمت وتُرسل معاً. إن تعطل Groq يكمل البوت بالنموذج المحلي تلقائياً.

بدون مفتاح Groq يتم التحويل على الخادم نفسه: على معالج 4 أنوية تأخذ محاضرة الساعة قرابة 25 إلى 30
دقيقة. خادم بكرت شاشة NVIDIA أسرع بكثير: ضع `WHISPER_DEVICE=cuda` و`WHISPER_COMPUTE_TYPE=float16`.

## التشغيل على الخادم (Docker)

```bash
git clone <رابط المستودع>
cd lecture-bot
cp .env.example .env
nano .env            # ضع TELEGRAM_BOT_TOKEN و ANTHROPIC_API_KEY
docker compose up -d --build
docker compose logs -f bot   # لمتابعة عمل البوت
```

## ملفات أكبر من 20 ميغابايت

خوادم تيليجرام لا تسمح للبوتات بتنزيل ملفات أكبر من 20 ميغابايت، ومحاضرة ساعة غالباً أكبر من ذلك.
الحل: تشغيل خادم Bot API خاص (مضمّن في `docker-compose.yml`) يرفع الحد إلى 2 غيغابايت:

1. ادخل https://my.telegram.org ← API development tools، وأنشئ تطبيقاً، وخذ `api_id` و`api_hash`.
2. شغّل سكربت التثبيت (`install.sh`) وأدخلهما عندما يسألك. أو أضف إلى `.env` يدوياً:
   ```
   TELEGRAM_API_ID=...
   TELEGRAM_API_HASH=...
   TELEGRAM_LOCAL_API_URL=http://telegram-bot-api:8081
   COMPOSE_PROFILES=bigfiles
   ```
   ثم `docker compose up -d --build`. البوت ينفّذ `logOut` من خوادم تيليجرام تلقائياً أول مرة.

بدون هذه الخطوة يعمل البوت، ويطلب من الطالب إرسال ملف أصغر أو رابط يوتيوب.

## التجربة بدون تيليجرام

```bash
pip install -r requirements.txt
```

## أوامر البوت

| الأمر | الوظيفة |
|---|---|
| /start | الترحيب وطريقة الاستخدام |

| /reminder | وقت التذكير اليومي بالمراجعة أو إيقافه (بتوقيت `REMINDER_TZ`، الافتراضي الرياض) |
| /exam | ملخص ليلة الاختبار: يختار الطالب محاضرات المادة فيصله ملف واحد |
| /library | المكتبة: المواد ومحاضراتها، وموعد الاختبار، وخطة المذاكرة |
| /search | البحث في كل المحاضرات |
| /groups | مجموعات الدراسة |
| /stats | إحصاءات الطالب |
| /wallet | المحفظة والأسعار والشحن |
| /invite | رابط الدعوة |
| /teacher | تفعيل نسخة المعلم أو إيقافها |
| /results | نتائج طلاب المعلم في اختباراته |
| /privacy | سياسة الخصوصية |

## الخصوصية

- التسجيل والملفات والصور تُحذف من الخادم فور انتهاء المعالجة.
- مع مفتاح Groq يُرسل صوت المحاضرة إلى Groq لتحويله إلى نص، ونص المحاضرة والشرائح إلى Claude.
- تُحفظ نصوص محاضرات الطالب وملخصاتها وأسئلتها (حتى 200 محاضرة) في `data/lectures`، لتعمل المكتبة
  وأزرار المذاكرة، ويستطيع حذفها كلها بـ /delete.
